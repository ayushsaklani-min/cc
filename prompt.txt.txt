### Target network: Midnight Preview (for development)
Midnight has two public test networks with distinct purposes (verified from the current
Midnight environments/endpoints page, Oct 2026):
- **Preview** — intended for early-stage development and experimentation. **This is our
  target for development.**
- **Preprod** — designed for final testing before mainnet deployment. We move here only
  for pre-mainnet validation, not now.
- **Mainnet** — production. Its hosted indexer/RPC were retired on 30 Sep 2026 and moved
  to Blockfrost (needs a project token). Do NOT hard-code Mainnet endpoints now.

Both Preview and Preprod run **ledger 8** on the same pinned stack, so nothing in the
contract or toolchain changes between them — only endpoints, wallet, and faucet.

**Use these Preview endpoints** (confirm they are still current in the spike against the

## Non-negotiable ground rules

1. **The spec is frozen; do not redesign it.** If something seems wrong, STOP and raise it
   in writing. No silent "improvements", renames, or trust-model changes. Label every
   unavoidable deviation explicitly.

2. **Never fabricate verification.** Do not claim code compiles, a proof verifies, a test
   passes, a wallet is funded, or a primitive exists unless you actually ran it and can
   show the output. "It should work" is banned. If you cannot run it, mark it UNVERIFIED.
   (This project already failed an audit for exactly this failure mode.)

3. **Honor every [SPIKE-BLOCKER] and open item in spec section 15.**
   - The ledger-8 chain-time primitive for `expiresAt` and the revocation bound is
     UNCONFIRMED. Find the real primitive from authoritative Midnight sources or by
     compiling; do not invent one. Until it is confirmed and the assertion is active, the
     contract is NOT deployable, and the CI gate must fail a build that leaves it commented.
   - The exact signatures of `persistentHash` over a struct, `jubjubSchnorrVerify`, and
     `ed25519Verify<32>` must be confirmed against the pinned compiler, not guessed.

4. **Pin the exact toolchain** (verified against Midnight's compatibility matrix):
   compiler **0.31.1**, compact-runtime **0.16.0**, on-chain runtime **3.0.0**,
   Midnight.js **4.1.1**, proof server **8.1.0**, Node 22+. **Reject compiler 0.31.0** — it
   has a soundness bug (silently dropped range constraint) that source review cannot
   detect. Verify versions before building and show the output.

5. **Security invariants are not optional.** Every invariant in spec section 4.2 and every
   mitigation in section 4 must be implemented with a corresponding test. The oracle/
   document trust root is an accepted, documented risk — do not pretend ZK closes it.
